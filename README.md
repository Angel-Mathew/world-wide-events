# Worldwide Events Dashboard

A dashboard about events held in different cities around the world, such as conferences, seminars, webinars and workshops.

## The problem
Event teams want to know where events happen, what type they are and how many people attend. I put this into one view with a map and filters.

## What you can explore
- Event type buttons (Conference, Seminar, Webinar, Workshop)
- City buttons (Amsterdam, Berlin, Boston, Chicago, Dubai, Hong Kong, London, Los Angeles, Melbourne, New York, Tokyo, Toronto)
- A world map of event locations
- Participant counts and a table by year, quarter and month

## What I found
The counts update with every filter. For example, picking one event type and one city shows how many participants attended and when. Events appear across North America, Europe, Asia and Australia, so the data is spread globally rather than in one region.
